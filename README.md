# Практическая работа №13: Личный веб-сайт студента-разработчика

## Описание проекта

Это личный веб-сайт студента-разработчика, представляющий собой многостраничное портфолио, которое сочетает в себе функции визитной карточки, галереи проектов и учебного дневника.

## Структура проекта

```
13 практическая/
│
├── index.html              # Главная страница
│
├── pages/                  # Директория дополнительных страниц
│   ├── projects.html       # Страница проектов
│   ├── diary.html          # Учебный дневник
│   └── contacts.html       # Страница контактов
│
├── styles/                 # Директория стилей
│   └── styles.css          # Основной файл стилей
│
├── scripts/                # Директория скриптов
│   ├── theme.js            # Переключение темной/светлой темы
│   ├── filter.js           # Фильтрация проектов
│   ├── diary.js            # Функционал дневника
│   └── contact-form.js     # Валидация контактной формы
│
├── images/                 # Директория изображений
│   └── icons/              # Поддиректория для иконок
│
└── assets/                 # Дополнительные ресурсы
    └── resume.pdf          # Резюме для скачивания
```

## Описание страниц

### Главная страница (index.html)
- Визитная карточка с фото и описанием
- Блок навыков с прогресс-барами (HTML/CSS 90%, JavaScript 80%, Bootstrap 85%, React 60%)
- Карточки лучших проектов с превью

### Страница проектов (projects.html)
- Адаптивная сетка проектов
- Фильтрация по категориям (Все, HTML, JS, React)
- Модальные окна с детальной информацией о каждом проекте
- Скриншоты и ссылки на живую версию/исходный код

### Учебный дневник (diary.html)
- Timeline с историей записей о прогрессе обучения
- Статусы записей: "Завершено" и "В процессе"
- Прогресс-бары текущих курсов
- Форма добавления новых записей
- Статистика: завершенные проекты, часы обучения, записи, сертификаты

### Страница контактов (contacts.html)
- Контактная форма с валидацией полей (имя, email, сообщение)
- Блок контактной информации (email, GitHub, местоположение)
- Ссылки на социальные сети
- Обработка отправки формы с сохранением в localStorage

## Технологии

- **HTML5** - семантическая разметка
- **CSS3** - стилизация, анимации, адаптивный дизайн
- **Bootstrap 5.3.2** - компонентная библиотека и сетка
- **JavaScript (ES6+)** - интерактивность и функционал
- **Bootstrap Icons** - иконки

## Функциональные возможности

### Переключение темы (theme.js)
- Светлая и темная темы
- Сохранение выбранной темы в localStorage
- Плавная анимация переключения

### Фильтрация проектов (filter.js)
- Фильтрация по категориям с анимацией
- Плавное появление/скрытие карточек проектов

### Учебный дневник (diary.js)
- Добавление новых записей через форму
- Сохранение записей в localStorage
- Форматирование даты
- Отображение статусов записей

### Валидация формы (contact-form.js)
- Проверка корректности email
- Проверка минимальной длины имени и сообщения
- Визуальная индикация ошибок
- Сохранение сообщений в localStorage

## Адаптивность

Проект полностью адаптивен и корректно отображается на всех устройствах:
- **Desktop** (>992px)
- **Tablet** (768px - 991px)
- **Mobile** (<767px)

## Стилевые особенности

- Градиентные фоны для заголовков
- Hover эффекты на карточках и кнопках
- Плавные анимации и переходы
- Тени и скругленные углы для современного вида
- Прогресс-бары с анимацией заполнения

## Как использовать

1. Откройте `index.html` в браузере
2. Навигация между страницами через меню
3. Используйте кнопку переключения темы в шапке сайта
4. На странице проектов - фильтруйте по категориям
5. В дневнике - добавляйте новые записи
6. На странице контактов - заполните и отправьте форму
